# Homelab

My homelab consists of a raspberry-pi called rasputin and an old computer running Truenas Community
Edition.

The idea of this homelab is that Rasputin does the compute and Truenas stores all the important data
that needs to be snapshotted and backed up.

How devices connect to rasputin:

- LAN devices connect via BIND DNS.
- Devices outside of my house connect via Tailscale.

## Dictionary

- Rasputin: the raspberry-pi that is running all of the services in my garage.
- Truenas: besides being Truenas the software, I call the box that's running "Truenas Community
  Edition" in my garage the same name since that is it's ONLY function.
